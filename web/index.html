Use the network, lines and groups above. Android 5.0 or newer · ARM tablets, including Fire 7 from 2015. The tablet uses its own Wi-Fi connection.

      
Enable Developer options and USB debugging on the tablet. Close other ADB tools before connecting. Approve the computer on the tablet when asked.

      

        
        
        
Motion dimming and startup
        
        

        
        
Motion dimming uses the front camera locally, about once a second. No images are saved or sent. It detects movement, not people, and dims the screen rather than putting the tablet to sleep. Camera permission is optional.

        

        
        
        
Some Fire OS versions block changing Home. Setup opens the tablet’s Home settings when automatic selection is unavailable.

        

        
Configure tablet Wi-Fi
          
          
Optional. Wi-Fi credentials go directly over USB to the app. Android or Fire OS may restrict network changes; setup reports refusals.

        

        
Dedicated tablet controls
          
          
Only for a dedicated tablet without accounts or an existing device owner. Android may refuse. Setup never resets the tablet. Use the app’s ••• menu to exit kiosk mode and open system settings.

        

      

      

      

      

      
The ADB host key is saved only in this browser and is never uploaded.

      
      

        Advanced ADB controls
        
ADB commands run without root by default. Root uses an existing su installation and may ask for approval on the tablet.

        
        
        
Commands can change security settings or erase tablet data. Review every command, including AI-generated commands, before running it.

        

        
        

        
        
Replacement removes the selected administrator before assigning Timetable. Android can refuse removal of a production administrator. Accounts, profiles and device data are kept.

        
        
        
        
        

        

      

      

        Battery and background apps
        
Read battery status and disable individual background apps without root. Android may restrict changes. Charging controls appear only when Android exposes a real writable battery threshold.

        

        

        

        

        

        
Install the latest Timetable app first. Select individual apps to stop their background services. Disabling keeps their data and can be reversed. Android core, launchers, settings, keyboards, administrators and Timetable are protected.

        

        

      

      
This is a development build. Updating an earlier installation requires the same signing key; setup keeps your data if Android refuses an update.
